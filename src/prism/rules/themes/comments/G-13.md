# G-13：导出符号必须有注释，且以符号名开头

**默认严重程度**：low

## 规则
- 导出的类型、函数、方法、常量都要有文档注释
- 注释以**符号名开头**（`// Load 读取配置……` 而不是 `// 读取配置……`）—— `go doc` 与 IDE 靠这个前缀做索引
- 句号与大小写按整句写；先说清楚「它是什么 / 做什么」，再补充细节
- 不要写成「实现了 foo 接口」这类废注释：说清它做什么，而不只是它属于谁

## 正例
```go
// Load 从 path 读取配置。文件不存在时返回 ErrNotFound。
func Load(path string) (*Config, error)
```

## 反例
```go
// 读取配置
func Load(path string) (*Config, error)   // 不以符号名开头
func Save(c *Config) error                 // 完全没有注释
```

## 边界情况
- 未导出的符号按需写注释 —— 有价值就写，不强制
- 被 `//go:build` 分离的文件、自动生成的代码不适用
