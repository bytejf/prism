# G-23：安全用途的随机数必须用 `crypto/rand`

**默认严重程度**：high

## 规则
`math/rand` 是可预测的伪随机：种子一旦被猜到（Go 1.20 之前默认种子固定），所有输出都能推出来。
凡是**攻击者不该预测**的值都必须用 `crypto/rand`：

- 令牌、会话 ID、API key、重置密码的链接
- 加密用的盐、初始化向量、nonce

非安全用途（抖动、采样、压测数据、游戏表现）用 `math/rand` 是对的。

## 正例
```go
buf := make([]byte, 32)
if _, err := rand.Read(buf); err != nil {     // crypto/rand
    return "", fmt.Errorf("generate token: %w", err)
}
return base64.RawURLEncoding.EncodeToString(buf), nil
```

## 反例
```go
token := fmt.Sprintf("%d", rand.Int63())      // math/rand：可预测，且取值范围也不够
```

## 边界情况
- 会进 URL 或命令行的 token 用 `base64.RawURLEncoding`（`StdEncoding` 的 `+` `/` `=` 都需要转义，容易被下游截断）
- 生成后要检查 `rand.Read` 的错误 —— 它失败时返回的是不完整的随机数据
