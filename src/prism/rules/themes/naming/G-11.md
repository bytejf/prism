# G-11：导出的取值方法不要带 `Get` 前缀

**默认严重程度**：low

## 规则
Go 里取值方法直接叫名词：`Name()` 而不是 `GetName()`。`Get` 前缀是 Java/C# 的习惯，
在 Go 里读起来啰嗦，而且和有副作用的操作分不开。

保留 `Get` 的场合：本身是**远程读取 / 有副作用 / 可能失败**的操作（`http.Get`、
`cache.GetOrLoad`），那时 `Get` 表达的是「去拿」，不是「读字段」。

## 正例
```go
func (u *User) Name() string
func (c *Cache) Get(key string) ([]byte, bool)   // 真的去查了一次，Get 名副其实
```

## 反例
```go
func (u *User) GetName() string
func (u *User) GetID() string
```

## 边界情况
- 与既有接口（`fmt.Stringer`、`driver.Valuer`）对齐时以接口为准
- 已经发布的导出方法改名会破坏兼容，新加的方法按这条来
