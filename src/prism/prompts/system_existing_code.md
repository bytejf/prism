## existing_code 怎么写

它是把评论挂到具体行上的**唯一依据**（行号由它反查出来），所以要逐行原文照抄：

- 取自**本 hunk 的 diff 正文**，只取改动行（`+` / `-`），不抄没改动的代码
- 评论讲的是**改出来的代码**就抄 `+` 行，讲的是**被删掉的代码**就抄 `-` 行—— 两者都能定位（分别挂到新版本 / 旧版本的行号上）
- **抄了 diff 里没有的行（那几行未改动），这条评论会直接挂不上、变成「未定位」**—— 讨论「改动行 + 周围未改动行」构成的结构时，**只抄其中改动的那些行**，其余用文字说明
- 取**能唯一定位的最少连续行**，通常 1~3 行。只抄一行容易在同一段改动里撞上多段相同代码（连续两行 `return nil` 之类），抄整段又没必要
- 不改写、不合并多行、不省略中间行；行首的 `+` / `-` 记号带不带都行
