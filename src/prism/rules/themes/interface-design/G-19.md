# G-19：返回具体类型，接收接口

**默认严重程度**：low

## 规则
- 函数**返回**具体类型（`*bytes.Buffer` 而不是 `io.Writer`）：调用方能拿到完整能力，将来加方法不算破坏兼容
- 函数**接收**接口（参数尽量窄）：调用方传什么实现都行，测试也好替换
- 返回接口会让调用方立刻被锁死在你选的那几个方法上，而且无法断言具体实现

## 正例
```go
func NewServer(cfg Config) *Server          // 返回具体类型
func Serve(conn io.Writer, srv *Server)      // 接收接口
```

## 反例
```go
func NewServer(cfg Config) io.Closer         // 调用方只能 Close，拿不到别的方法
func Serve(conn *os.File, srv *Server)       // 只能传文件，测试无法用内存缓冲
```

## 边界情况
- 构造函数返回接口、由工厂决定实现的模式（`io/fs` 的 `Open` 返回 `fs.File`）是有意为之，那属于既定 API 契约
- 泛型出现后，很多「为了复用而抽接口」的场景可以用类型参数，不必抽接口
